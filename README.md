# 🗄️ Repositório de Estudos - SQL
Repositório destinado ao registro contínuo dos conteúdos, exemplos e exercícios práticos da disciplina de Banco de Dados.

## 📚 Estrutura das Aulas
* **Aula 01:** Conceitos teóricos e introdução ao PostgreSQL.
* **Aula 02:** Criação de banco de dados, tabelas (`CREATE TABLE`) e inserção de dados (`INSERT INTO`). Exemplo focado no sistema de uma Loja de Informática.

## 🛠️ Tecnologias e Ferramentas
* **SGBD:** PostgreSQL
* **Interface Gráfica:** DBeaver
